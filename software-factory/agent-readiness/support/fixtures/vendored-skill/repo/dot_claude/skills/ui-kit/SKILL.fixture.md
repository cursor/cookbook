# ui-kit

Components are added as source code to the project through the ui-kit CLI. Run it with the project's package runner.

## Commands

- Set up a project: `npx ui-kit@latest init`
- Add a component: `npx ui-kit@latest add <component>`
- Read a component's docs: `npx ui-kit@latest docs <component>`
- Search the registries: `npx ui-kit@latest search --json`
- The date examples need a helper: `pnpm add date-fns`
